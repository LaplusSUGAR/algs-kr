# 직접 넣는 팀 로고

Liquipedia와 공식 API 어디에도 로고가 없거나, 자동으로 고른 로고가 틀렸을 때 여기에 그림 파일을 넣습니다.
이 폴더의 파일이 가장 먼저 쓰입니다 (운영자 파일 > Liquipedia > 공식 API).

- 파일 이름: `<팀 약칭>.png` (밝은 배경용, 보통 어두운 색 로고)
- 어두운 배경용(흰 로고)이 따로 있으면: `<팀 약칭>@dark.png`
- 약칭이 없는 2부(챌린저 서킷) 팀은 화면에 보이는 팀 이름 그대로: `Laugh Tale.png`
- 이름이 바뀐 2부 팀은 새 이름으로: `ORB GARDEN.png` (옛 이름 로고는 새 이름에 쓰지 않습니다)
- png · webp · jpg · svg 가능. 크기는 상관없습니다 (빌드가 투명 여백을 자르고 64px·160px WebP로 줄임)
- 배경이 투명한 그림이 가장 좋습니다. 캡처한 그림이면 로고 둘레를 바짝 잘라서 넣어 주세요

올리면 몇 분 뒤 자동 빌드가 반영합니다. 결과는 `raw/logos/report.json`(팀마다 쓴 출처와 이유)에서 확인할 수 있습니다.

## 같은 로고를 쓰는 팀

같은 조직의 두 팀(예: RIDDLEORDER ZERO·ONE, 본 팀과 아카데미)이 같은 로고를 쓰면, 로고 아래에 구분 띠(ZERO·ONE·ACADEMY)를 넣은 그림을 여기에 둡니다.
사이트는 로고 위에 따로 표시를 덧붙이지 않습니다.

- RIDDLEORDER: 검은 띠 + 노란 글자 (`RID0.png`, `RID1.png`)
- 아카데미: 팀 색 띠 + 흰 글자 (`UNLIMIT ACADEMY.png`, `FF.png`, `For Fun Academy.png`)
- 같은 조직의 다른 지역 팀: 지역 띠 (`VOID.png` = OCE, `VE.png` = EMEA). 흑백 로고라 `@dark` 는 흰 로고 + 흰 띠로 따로 만듭니다.
- 컬러 로고는 밝은·어두운 배경 모두에서 보이도록 만든 한 장이라 `@dark` 파일도 같은 그림입니다.
- 프로리그 약칭과 2부(챌린저 서킷) 이름이 다르면 두 이름으로 같은 그림을 둡니다 (예: `FF.png` · `For Fun Academy.png`).
