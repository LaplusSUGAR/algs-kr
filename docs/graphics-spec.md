# 결과 그래픽 디자인 규격 (EASY ALGS KR)

라운드가 끝날 때마다 만드는 **경기 결과** 그림과 **POI 드래프트** 그림의 규격이다.
2026-11 LCQ APAC North 때 손으로 만든 4장(승자 1R 결과, 승자 2R·패자 1R 결과, 승자 2R·패자 1R POI, 패자 2R POI)을 기준으로 정리했다.
자동 생성 스크립트 `scripts/graphics.mjs` 가 이 규격을 그대로 따른다. **디자인을 바꾸면 이 문서와 스크립트를 함께 고치고, 스크립트의 `SPEC_VER` 를 1 올린다**(이미 만든 그림이 새 규격으로 다시 만들어진다).

---

## 1. 언제, 무엇을 만드나

| 그림 | 만드는 때 | 필요한 데이터 |
|---|---|---|
| 결과 (`-results.png`) | 그 경기(시리즈)가 `completed` 이고 결과가 있을 때 | 공식 API 시리즈 결과(순위·점수·킬) |
| POI (`-poi.png`) | 그 경기의 **POI 드래프트가 끝났을 때**(공식 `done`) | 공식 POI 드래프트 선택(지점·좌표) |

- **경기(시리즈) 하나당 한 장**(11-21 운영자 확정). 승자 1R 로비 A·B 도, 동시에 하는 승자 2R·패자부활 1R 도 각각 따로 만든다.
- **실제 데이터만** 쓴다. 결과가 비었거나 드래프트가 끝나지 않았으면 그림을 만들지 않는다. 가짜·예상 값으로 채우지 않는다. 아직 정해지지 않은 다음 경기 자리는 `?` 칸으로 둔다(§4.5).
- 대상 대회: 대진 규칙(`config/rules/<시즌>.json` 의 `brackets`)이 있는 LCQ·챔피언십. 그 밖의 대회는 아직 자동으로 만들지 않는다.
- 대상 지역: `config/graphics.json` 의 `regions`. 기본 `["kr"]` = 한국 관련 팀(한국 선수·코치가 있는 팀 포함)이 출전한 지역. `"all"` 이나 `"apac-s"` 처럼 직접 적을 수도 있다.
- 공식 데이터가 나중에 고쳐지면(벌점 등) 같은 파일 이름으로 다시 만든다(데이터 지문 비교, `graphics/index.json`).

## 4. 배치

### 4.1 머리 (두 그림 공통)

```
▌ [LCQ] [APAC NORTH]                                  EASY ALGS
▌ 큰 제목                                                     KR
▌ 부제 (날짜 · 방식 · 팀 수 · 게임 수 · 진출 규칙)
```
- 왼쪽 6px 빨간 막대. 배지: 대회(빨강 채움, `LCQ`/`CHAMPIONSHIP`) + 지역(선 테두리, 대문자).
- 오른쪽 위 `EASY ALGS` (흐림, 넓은 자간) / `KR` (흰색, 크게).
- **제목**
  - 결과: `승자 2라운드 결과`, 로비는 `승자 1라운드 로비 A 결과`
  - POI: 항상 `POI 드래프트`
- **부제**: 날짜는 `11월 21일(토) 12:00`(한국 시간) 꼴. 이어서
  - 결과: `20팀 · 6게임 · 상위 10팀 승자 2R, 하위 10팀 패자부활 1R` (결승은 `상위 2팀 챔피언십 진출`)
  - POI: `{경기 이름} · {날짜} · {지도1} · {지도2} · 20팀`

### 4.2 한국 팀 카드 (머리 바로 아래)

- 이 라운드에 나온 한국 관련 팀마다 카드 1장. 3장까지 한 줄(1장이면 전체 폭, 2장이면 반반), 4장부터 줄을 바꾼다.
- 카드: 판 색 + 왼쪽 4px KR 파랑 막대, 6px 모서리.
- **결과 카드**: 로고 60px · `약칭` + 작은 전체 이름 · 한 줄 요약 · 결과 줄
  - 요약: `로비 A 11위 · 31점 14킬 (10위와 2점 차) · ILY · 코치 YunD, sedna`
    - 진출선 바로 위·아래(10위·11위)면 괄호로 점수 차를 붙인다.
    - 한국 선수 이름, 그다음 `코치 …`.
  - 결과 줄: `▲ 승자 2R 진출`(청록) / `▼ 패자부활 1R`(호박) / `✕ 탈락`(밝은 빨강) / 결승은 `★ 챔피언십 진출`(호박) 또는 `N위로 마감`(흐림).
  - 순서: 챔피언십 → 진출 → 마감 → 패자부활행 → 탈락, 같은 줄이면 단계 순서 → 순위.
- **POI 카드**: 로고 44px · 약칭 · 단계(청록, 로비면 `승자 1R 로비 A`) · 지도별 칸 2개(지도 이름 대문자 라벨 / 지점 이름 / `7번째 선택` 호박).
- **한국 팀이 없는 라운드**: 카드 대신 안내 판 1장.
  - 큰 줄: `상위 10팀이 11.22(일) 17:00 매치 포인트 결승에 진출해요` (`상위 10팀`·도착 단계 이름은 호박)
  - 작은 줄: `이번 라운드에는 한국 팀이 없어요 · RID0·KN은 승자 2R에서 결승 직행 · FNC는 패자부활 1R에서 탈락` — 한국 팀의 이번 대회 마지막 결과. 조사 은/는 은 약칭을 한국어로 읽은 받침으로 정한다.

### 4.3 결과 표 (결과 그림)

- **판 2개 좌우: 왼쪽 1~10위, 오른쪽 11~20위**(세로를 줄이려고 반씩, 11-21 운영자 확정). 판 제목은 `/ 1~10위`, `/ 11~20위`.
- 진출선이 가운데(10위)와 같으면 선을 긋지 않고 판 제목 오른쪽에 `▲ 승자 2R`(왼쪽 판, 청록) / `▼ 패자부활 1R`(오른쪽 판, 호박) 또는 `▼ 탈락`(밝은 빨강)을 단다.
- 진출선이 가운데가 아니면(결승 상위 2팀 등) 그 자리에 빨간 점선 줄을 넣는다(`★ 챔피언십`).
- 열: `#` · `팀`(로고 32px + 약칭 / 전체 이름, 한국 팀은 오른쪽 끝에 KR 배지) · `킬` · `점수`. 행 높이 50px.
- 순위 숫자: 진출권은 청록, 아래는 흐림.
- 결과는 공식 순위 그대로(같은 점수의 순서도 공식 순위).

### 4.4 POI 판 (POI 그림)

- 판 1개(전체 폭). 제목 `/ 승자 2라운드`(로비면 `승자 1라운드 로비 A`) + 오른쪽 날짜.
- **지도 2장 좌우**: 위에 지도 이름(대문자, 넓은 자간). 바탕 그림은 `site/poi/base/<지도>.webp`(공식 사이트 그림), 정사각형.
- **핀**: 공식 좌표(%) 위치에 지름 30px 원(바탕색 + 흰 2px 테두리) 안에 팀 로고, 아래 약칭(흰 글자, 검은 그림자).
  - **한국 팀 핀**: 지름 38px, KR 파랑 3px 테두리 + 흰 바깥선, 약칭은 KR 파랑 알약. 다른 핀 위에 그린다.
- **선택 표**(지도 아래, 좌우 반반): `팀 | 지도1 | 지도2`. 칸은 `작은 선택 순서 + 지점 이름`.
  - 팀 순서 = 그 팀의 가장 이른 선택 순서(드래프트 시드 순). 앞 절반은 왼쪽, 나머지는 오른쪽.
  - 한국 팀 행은 KR 행 배경 + 왼쪽 파란 막대 + KR 배지.
  - 지점 이름이 전부 대문자로 온 지도는 첫 글자만 대문자로 맞춘다(`SKYHOOK WEST` → `Skyhook West`).

### 4.5 다음 경기 명단 (결과 그림 아래)

- 이 경기가 팀을 보내는 다음 단계마다 판 1개(최대 2개 좌우). 로비 그림이면 다른 로비에서 오는 팀도 함께 보인다. 제목 `승자 2라운드` + 오른쪽 그 경기 날짜(호박).
- 설명 줄: `상위 10팀 매치 포인트 결승 · 하위 10팀 패자부활 2R` (`매치 포인트 결승` 청록, `탈락` 밝은 빨강). 결승은 `상위 2팀 챔피언십 진출`.
- 팀 칸 4열: 로고 28px + 약칭 + 출처 꼬리표.
  - 로비에서 온 팀: `A1`, `B1`, `A2` … (로비 순서를 번갈아)
  - 그 밖: `승2R 11위`, `패1R 1위` (출처 단계 순서대로)
  - 한국 팀 칸: KR 칸 배경 + KR 파랑 테두리.
  - **아직 안 끝난 단계에서 올 자리**: 회색 `?` 상자 + `패2R 1위` / `17:00 결정`.

### 4.6 바닥글

- 위에 선 1px, 왼쪽 출처, 오른쪽 `laplussugar.github.io/algs-kr`.
- 결과: `시각은 한국 시간 · 점수·킬·다음 경기 명단: ALGS 공식 데이터 (11.21(토) 16:10 기준)` — 기준 시각은 공식 API 를 받은 시각.
- POI: `지도의 핀은 팀별 낙하 지점 · 표의 작은 숫자는 드래프트 선택 순서 · 출처: ALGS 공식 POI 드래프트`

## 5. 한국 팀·선수 강조 규칙

- **한국 관련 팀** = 사이트의 한국 관련 기준(`A.kr`, `krLevel` 이 `none` 이 아닌 팀): 한국 팀, 한국 선수가 있는 팀, 한국 코치만 있는 팀(예: KN) 모두 같은 강조.
- 강조는 **KR 파랑 한 색**으로만 한다: 카드 왼쪽 막대, 표 행 배경 + 왼쪽 4px 막대, `KR` 배지(파랑 채움, 흰 글자, 4px 모서리), 다음 경기 칸 테두리, POI 핀 테두리·약칭 알약.
- 팀 색(로고 색)이나 사용자의 '대표 응원 팀'은 그림에 쓰지 않는다(누가 봐도 같은 그림).
- 한국 선수·코치 이름은 카드 요약 줄에만 적는다. 표에는 적지 않는다.

## 6. 로고

- 사이트가 쓰는 로고(`site/logos/t/<id>-160.webp`)의 **어두운 배경용**(흰 로고 우선).
- 같은 로고를 쓰는 팀(RIDDLEORDER ZERO·ONE, 아카데미, 지역이 다른 VOID)은 사이트처럼 구분 띠가 들어간 그림을 쓴다(`logos-src/`).
- 로고가 없으면 칸 색 상자에 약칭 앞 두 글자(`CA`, `OR`) 흐린 글자.

## 7. 글 쓰는 법

- 단계 이름: 제목·판 제목은 `승자 2라운드`, 문장·꼬리표는 `승자 2R`·`패자부활 1R`·`매치 포인트 결승`, 아주 짧은 칸은 `승2R`·`패1R`.
- 날짜: 부제는 `11월 21일(토) 12:00`, 판 오른쪽·문장은 `11.21(토) 12:00`. 모두 한국 시간.
- 팀은 공식 약칭(2부 팀 약칭 겹침은 사이트 규칙 `lcqShortFix` 를 따름), 전체 이름은 공식 이름 그대로.
- 기호: `▲` 진출 · `▼` 아래 단계 · `✕` 탈락 · `★` 챔피언십. 구분점은 ` · `.

## 8. 파일 이름·폴더

```
graphics/
  index.json                         만든 그림 목록 (파일 → 종류·지역·대회·시작 시각·데이터 지문·만든 때·시리즈)
  <시즌>/<대회 종류>/<지역>/<한국 날짜>-<한국 시각>-<단계>-<종류>.png
```
- 시즌: `year-6` · 대회 종류: `lcq`, `championship` · 지역: `apac-n`, `apac-s`, `emea`, `americas`
- 날짜·시각: 라운드 시작 한국 시간 `YYYYMMDD-HHMM`
- 단계: 규칙 파일의 단계 키. 승자 1R 로비 A·B 는 `wr1a`·`wr1b`. 예: `wr2`, `er1`, `er2`, `f`
- 종류: `results`(결과), `poi`(POI 드래프트)
- 예: `graphics/year-6/lcq/apac-n/20261121-1200-wr2-results.png`, `graphics/year-6/lcq/apac-n/20261121-1700-er2-poi.png`
- 파일 이름은 영문 소문자·숫자·하이픈만(게시판 업로드·주소에서 깨지지 않게). 한국어 이름은 `index.json` 의 `title` 에.

## 9. 자동 생성

- `scripts/graphics.mjs` — 빌드가 만든 `site/data/algs-data.js` 만 읽는다(따로 공식 API 를 부르지 않음).
- 워크플로 `build.yml` 의 '결과·POI 그래픽' 단계가 5분마다 `--plan` 으로 확인하고, 새로 만들 그림이 있을 때만 `pretendard`·`sharp`·`playwright-core` 를 설치해 그린 뒤 데이터와 함께 커밋한다. 실패해도 빌드는 계속된다.
- 경기가 끝나고 공식 API 에 결과가 `completed` 로 올라오면 다음 빌드(5분 안)에 그림이 생긴다.
- 손으로 돌리기:
  ```
  npm i --no-save --no-package-lock pretendard@1.3.9 sharp@0.33 playwright-core@1.47.2
  node scripts/graphics.mjs            # 새로 만들 것만
  node scripts/graphics.mjs --force    # 전부 다시
  node scripts/graphics.mjs --only er2 # 이름에 er2 가 든 것만
  node scripts/graphics.mjs --html     # HTML 만 graphics/_html/ 에 (디자인 확인용)
  ```
  작업 공간 Chrome 은 `CHROME_PATH=/opt/pw-browsers/chromium`.
