# ALGS Year 6 챔피언십 가이드 영상 대본 — 의도 확정 (2026-11-24)

## 목표 (Why)

- 운영자가 만든 엑셀 초안(`ALGS_Year6_Championship_*.xlsx`, 17장면·약 9분 19초, Split 2 플레이오프 편 참고 영상 구성을 따름)을 바탕으로 **설명 흐름과 내용 배치를 다시 짠 새 대본**을 만든다.
- 시청자: Apex 는 알지만 ALGS 방식(조별 리그, 승자조·패자조, 매치포인트 결승)이 헷갈리는 한국 팬.
- 1순위: 설명 흐름·내용 배치. 한국 팬 관점 내용은 **마지막 부분**에 넣는다.

## 완료 기준 (Success)

- 뼈대는 시청자가 대회를 겪는 순서:
  프롤로그 → 누가 왔나(CP 직행 32 + LCQ 8) → 목·금 조별 리그 → 토요일 승자조·패자조 → 일요일 매치포인트 결승 → 한국 팬 관점 → 보는 법·에필로그
- 규칙은 처음 필요한 장면에 끼워 넣는다.
  - 점수 규칙(순위 점수 + 킬): 첫 시리즈를 설명할 때
  - POI 드래프트·레전드 밴: 목요일 첫 시리즈 안에서 "한 시리즈에서 벌어지는 일"로 묶음
  - 50점 매치포인트: 일요일 결승 장면에서
- 초안의 '다운 이후의 선택'처럼 질문만 던지고 답이 없는 장면은 답을 주거나 뺀다.
- 형식: 초안과 같은 열 — 타임코드/장면 · 녹음용 내레이션 · 편집 지시/화면 자막 · 출처 키.
- 분량은 신경 쓰지 않는다.
